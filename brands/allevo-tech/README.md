# Allevo Tech — o estilo em uma tela

Anúncio vertical da **formação em analista de dados**, mesmo apresentador e cenário do Clube (parede de
plantas + estante). Criado em 2026-09-25 (C2546–C2550). Valores em `brand.json`.

| | |
|---|---|
| **formato / ritmo / cor** | herdados do Clube: 1080×1920, 29,97 fps, −14 LUFS, pausas > 0,45s encurtadas, **1,25x**, look `natural` |
| **legenda** | **Geist SemiBold** (`fonts/Geist.ttf`, variável), preenchimento **#00FFBB**, traço `#030303` (mantido do Clube); 60% da altura, ≤4 palavras, minúsculas |
| **logo** | `logo/logo-mono-darkbg.png` (monocromático para fundo escuro), 340px, centralizado, 80px do topo |
| **rodapé** | **sem letras miúdas** |
| **trilha** | `carreira-112bpm-a.mp3` em `presence 0` (tão presente quanto a do Clube, medido em 1–8 kHz; grave cortado se passar); o ataque de 38,96s na última palavra |
| **efeitos** | A: riser → micro-silêncio → whoosh + impact na virada "Na formação…" · B: toque no CTA "toca no botão/clicar aqui", impact seco em "Não precisa." · C: glitch na sobrecarga ("cinco ferramentas", "lista de ferramentas"), chime de conquista **uma vez** (certificados/projetos), teclado em "planilha", tic-tac em "chegando atrasado" |
